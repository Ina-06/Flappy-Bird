# Flappy Bird

A retro Flappy Bird clone in Java, built with Swing and drawn at 60 frames per second.

## How to play

- **Space** to flap
- Fly through the gaps between pipes. Each pipe you pass scores a point.
- Hit a pipe or fall off the screen and it's game over. Press **Space** to restart.

## Run it

Requires a JDK (8 or newer).

```bash
cd "FlappyBird/Flappy Bird/src"
javac *.java
java App
```

**Built with:** Java · Swing · AWT
